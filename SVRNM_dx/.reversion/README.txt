The archive is structured as follows:

README.txt -- this file

common   -- source files for modules commonly used throughout the training.
     EEnet    -- EEnet-based components
     libs     -- Libraries used in examples and exercises
     packages -- SystemVerilog packages used in examples/exercises

examples   -- Code examples included in the training presentation sessions.

exercises  -- Lab exercises for the trainee. Each is associated with a 
              presentation session, indicated by the name of the folder,
              e.g. Session_01

scripts    -- repository of scripts used to run the examples and exercises,
              and to maintain the repository. Be sure to call setup from the
              top level directory before engaging with examples or exercises.
